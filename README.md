The first Italian platform for ant identification. Live at **[formicheditalia.it](https://formicheditalia.it)**

## Features

- **Interactive multi-access key** for 43 Italian ant genera (8 subfamilies) with Shannon entropy-weighted scoring
- **Species catalog** of 80 species documented in Rome (75 from thesis + 5 additions; expanding to 267+ Italian species)
- **Expert directory** of 11 Italian myrmecologists
- **Interactive anatomy glossary** with 31 clickable terms and original illustrations
- **Bilingual** (Italian/English) with 441 translation keys
- **PWA** with offline identification key support
- **100% specimen photo coverage** from AntWeb.org (CC BY-SA 3.0)
- **Contact form** with Web3Forms integration and honeypot spam protection
- **GDPR-compliant** privacy policy and cookie banner

## The identification algorithm

Unlike traditional dichotomous keys, this platform uses a **weighted multi-access approach**:

1. Characters can be selected in any order
2. Each selection is weighted by **Shannon entropy** (information gain) at selection time
3. Genera are ranked by compatibility score, not eliminated
4. **Subfamily-aware penalization** adjusts scores when the implied subfamily is detected
5. Adjustable error tolerance (0-3 mismatches) compensates for observation errors
6. The system suggests the next most discriminative character

Full algorithm documentation: [formicheditalia.it/metodi](https://formicheditalia.it/metodi)

## Tech stack

- **Framework**: [Astro](https://astro.build) 5.x with React islands (TypeScript)
- **Styling**: Tailwind CSS 3.x
- **Data**: Static JSON generated by Python scripts from NEXUS character matrices
- **Hosting**: Vercel (static deploy)
- **Images**: AntWeb.org specimens (CC BY-SA 3.0), anatomy illustrations by Maurizio Mei

## Project structure

```
formiche-ditalia/       # Astro website (src, public, config)
scripts/                # Python data pipeline (NEXUS parser, enrichment)
docs/                   # Research documentation
```

## Development

```bash
cd formiche-ditalia
npm install
npm run dev             # Dev server at localhost:4321
npm run build           # Static build (147 pages)
```

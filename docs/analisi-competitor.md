# Analisi Competitor — Formiche d'Italia (Aprile 2026)

## Differenziatori unici di Formiche d'Italia

1. **Scoring pesato con entropia Shannon** — nessun competitor lo ha. Lucid usa eliminazione semplice, AntWiki chiavi dicotomiche, iNaturalist usa AI
2. **Focus italiano + bilingue IT/EN + rete esperti** — nessun'altra piattaforma combina ID formiche italiane con lingua italiana e directory mirmecologi
3. **Design moderno responsive + PWA offline** — il design migliore di tutto il panorama (AntWeb datato, AntWiki wiki, Lucid desktop-era)
4. **Chiarezza single-purpose** — workflow 3 passi: identifica > esplora genere > trova esperto
5. **Approccio educativo** — glossario tooltip, InfoTip, anatomia interattiva

## Quick wins da implementare (alta priorità)

1. **Illustrazioni stati carattere nella chiave** — piccoli SVG accanto a ogni opzione ("peziolo con nodo" vs "senza nodo")
2. **Sezione "Generi simili"** nelle pagine genere — i 2-3 generi più confondibili con spiegazione differenze
3. **Shortcut "formiche in casa"** — link diretto dalla chiave pre-filtrato per generi domestici
4. **CSS print-friendly** per risultati identificazione
5. **Schema.org arricchito** — TaxonName, ImageObject, WebApplication

## Features da v2.0 (ispirate dai competitor)

1. **Confronto side-by-side immagini** (da AntWeb + CIVIK)
2. **Mappa distribuzione interattiva** (da Antmaps — Leaflet/MapLibre)
3. **AI photo pre-filter** (da iNaturalist + AntScout)
4. **Quiz/learning modules** (da Discover Ants)
5. **Line drawings per stati carattere** (da Antkey)

## Gap di contenuto vs competitor

1. Nessun dato distribuzione/mappe
2. Nessun contenuto video
3. Nessun sistema osservazioni community
4. Referenze bibliografiche limitate

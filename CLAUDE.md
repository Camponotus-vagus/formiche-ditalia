## Project Overview

"Formiche d'Italia" — the first comprehensive Italian ant species directory with interactive multi-access identification key, species/genus catalog, and expert network. Built as a static Astro site from FormiKey thesis data (NEXUS character matrices) and enriched with OpenAlex and AntWeb data. Bilingual IT/EN.

## Tech Stack

- **Framework**: Astro 5.x with React islands (TypeScript)
- **Styling**: Tailwind CSS 4.x
- **Data**: Static JSON files in `src/data/`, generated by Python scripts in `scripts/`
- **Hosting**: Vercel (free tier, static deploy)
- **Images**: Referenced from AntWeb (CC-licensed) + local fallbacks

## Commands

```bash
npm run dev           # Astro dev server
npm run build         # Static site → dist/
npm run preview       # Preview production build

# Data pipeline (run manually when source data changes)
python scripts/parse_nexus.py      # NEXUS → characters.json, matrix.json
python scripts/parse_excel.py      # Excel schede → genera/species descriptions
python scripts/build_experts.py    # OpenAlex API → experts.json
```

## Data Sources (in project folder, NOT in the Astro app)

### NEXUS Files (FormiKey thesis)

Two versions exist. Scripts prefer `TESI FORMICHE (Dropbox)/Matrici corrette da Rigato/` (expert-validated), falling back to `TESI FORMICHE/` for missing files.

- `sottofamiglie.nex` — 9 characters × 7 subfamilies
- `generi *.nex` — ~14-50 characters × genera per subfamily (Myrmicinae has 19 genera, 50 chars)
- `Specie *.nex` — characters × species per genus

NEXUS format: plain text with `BEGIN TAXA`, `BEGIN CHARACTERS`, `MATRIX` blocks. Character states can be polymorphic (`{0 1}`), missing (`?`), or gap (`-`).

### Excel Files

- `TESI FORMICHE (Dropbox)/Schede formiKEY/` — Descriptive sheets for genera, subfamilies, species
- `TESI FORMICHE (Dropbox)/Matrici corrette da Rigato/*.xlsx` — Corrected matrices in spreadsheet form
- `TESI FORMICHE (Dropbox)/Matrici Specie di Roma/*.xlsx` — Species matrices for Rome area

### Text Files (in `Formiche/`)

- `Sottofamiglie.txt` — 7 subfamilies
- `Generi.txt` — 41 genera grouped by subfamily
- `Specie.txt` — 75 species grouped by subfamily
- `Generi/Generi di [Subfamily].txt` — Genera per subfamily (asterisk = has species files)
- `Specie/[Subfamily]/Specie di [Genus].txt` — Species lists per genus

### Specimen Images

In `Formiche/Specie/[Subfamily]/[Species name]/`, following AntWeb conventions: `{specimen_id}_{view}_{number}_high.jpg`. Views: `h`=head, `p`=profile, `d`=dorsal, `l`=label.

## Architecture

### Site Structure

- `/identifica` — Interactive multi-access identification key (React island)
- `/generi` + `/generi/[slug]` — ~41 genus pages (static, generated from `genera.json`)
- `/specie/[slug]` — ~75 species pages (accessed from genus pages, no index)
- `/esperti` + `/esperti/[slug]` — Expert directory (~20-50 profiles)
- Editorial pages: homepage, `/chi-siamo`, `/come-identificare-le-formiche`, `/formiche-in-casa`

### React Islands (client-side interactivity)

Only 4 components are hydrated: `IdentificationKey.tsx`, `LanguageSwitcher.tsx`, `FilterBar.tsx`, `GlossaryTooltip.tsx`. Everything else is zero-JS Astro.

### Identification Key Algorithm

Multi-access key with error tolerance (unique differentiator). Genera are scored by compatibility, not rigidly eliminated. A genus matching 4/5 characters stays visible. Features: geographic pre-filtering by Italian region, visual glossary tooltips, best-character suggestion (information gain).

### i18n Model

Single-URL with Italian canonical paths. `LanguageSwitcher` swaps content client-side (`description_it` ↔ `description_en`, UI strings from `i18n/*.json`). `hreflang` tags with `?lang=en` for SEO.

## Key Counts

- 7 subfamilies, ~41 genera, 75 species (MVP, expandable to 267 via Schifani 2022)
- Myrmicinae is the largest subfamily (19-21 genera, 38 species)

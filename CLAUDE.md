## Project Overview

"Formiche d'Italia" — the first comprehensive Italian ant identification platform with interactive multi-access key, genus/species catalog, expert network, and interactive anatomy glossary. Built as a static Astro site from FormiKey thesis data (NEXUS character matrices). Live at https://formicheditalia.it

**Taxonomic scope:**
- **Genera**: All 39 genera present in the Italian peninsula (7 subfamilies), all with descriptions IT/EN
- **Species**: 75 species documented in the city of Rome (from FormiKey thesis, 2016-2017), all with descriptions IT/EN, habitat notes, and body length
- **Future**: Expansion to 100-130 Lazio species, then 267+ Italian species (Schifani 2022 checklist). See `docs/espansione-lazio.md` and `docs/articoli-scientifici-recenti.md`

## Tech Stack

- **Framework**: Astro 5.x with React islands (TypeScript)
- **Styling**: Tailwind CSS 3.x (pinned for @astrojs/tailwind compatibility)
- **Data**: Static JSON in `formiche-ditalia/src/data/`, generated by Python scripts
- **Hosting**: Vercel (static deploy), custom domain formicheditalia.it (Dynadot DNS)
- **Images**: Local specimen photos from AntWeb (CC BY-SA 3.0) in `public/images/`; anatomy illustrations by Maurizio Mei in `public/images/anatomy/`
- **PWA**: Service worker for offline identification key usage
- **SEO**: Google Search Console configured, sitemap auto-generated, Schema.org/Taxon structured data

## Commands

```bash

npm run dev           # Dev server localhost:4321
npm run build         # Static build → dist/ (136 pages)

# Data pipeline (from project root)
python3 scripts/parse_nexus.py                    # NEXUS → JSON
python3 scripts/parse_excel.py                    # Excel → enrich descriptions
python3 scripts/build_experts.py                  # OpenAlex → expert profiles
python3 scripts/copy_antweb_photos.py             # AntWeb images → public/
python3 scripts/copy_thesis_photos.py             # Thesis specimens → public/
python3 scripts/improve_characters.py             # Character IT translation + body regions
python3 scripts/enrich_publications.py            # OpenAlex → structured publications
python3 scripts/enrich_species_descriptions.py    # Generate species descriptions IT/EN
python3 scripts/enrich_genera_descriptions.py     # Generate genus descriptions IT/EN

# Deploy
npx vercel deploy --prod --force   # from formiche-ditalia/
```

## Identification Key Scoring (core innovation)

Located in `src/components/IdentificationKey.tsx` (~800 lines):
- **Weighted scoring**: Selections weighted by Shannon entropy at selection time
- **Subfamily-aware**: Out-of-scope genera penalized when implied subfamily detected
- **4-component UX**: Progress bar, gap indicator, impact badges (-N), suggested character
- **Mobile-first**: Progress + Diagnosis panels appear at top on mobile, in sidebar on desktop
- **Clickable genera**: Genus names in Diagnosis panel scroll to their card
- **InfoTip tooltips**: Interactive help for beginners on all key UI elements

## i18n

200+ keys in `src/i18n/{it,en}.json`. Two mechanisms:
- UI strings: `data-i18n="key"` swapped by LanguageSwitcher
- Data fields: `data-i18n-field="name" data-it="..." data-en="..."`
- Language persistence: BaseLayout script re-applies stored language on page load

## Important Notes

- Species status field: "native", "exotic", or "endemic". Exotic species (L. humile, M. pharaonis, C. nuda, S. membranifera) must never be marked "native"
- Canonical URLs always point to https://formicheditalia.it (not vercel.app)
- og:image must be absolute URL with https:// prefix, PNG format (not SVG)
- Anatomy image filenames use hyphens (not spaces): e.g., `frontal-carina.png`
- The project creator is Francesco Simone Mensa (full name always used), independent from MUSE

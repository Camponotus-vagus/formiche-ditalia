## Project Overview

"Formiche d'Italia" — the first comprehensive Italian ant species directory with interactive multi-access identification key, species/genus catalog, and expert network. Built as a static Astro site from FormiKey thesis data (NEXUS character matrices) and enriched with OpenAlex and AntWeb data. Bilingual IT/EN. Live at https://formiche-ditalia.vercel.app

## Tech Stack

- **Framework**: Astro 5.x with React islands (TypeScript)
- **Styling**: Tailwind CSS 3.x (pinned for @astrojs/tailwind compatibility)
- **Data**: Static JSON files in `formiche-ditalia/src/data/`, generated by Python scripts in `scripts/`
- **Hosting**: Vercel (static deploy)
- **Images**: Local specimen photos from AntWeb (CC BY-SA 3.0) in `public/images/`
- **PWA**: Service worker for offline identification key usage

## Commands

```bash
# Website (run from formiche-ditalia/)
npm run dev           # Astro dev server on localhost:4321
npm run build         # Static build → dist/ (130 pages)

# Data pipeline (run from project root)
python3 scripts/parse_nexus.py           # NEXUS → 5 JSON files
python3 scripts/parse_excel.py           # Excel schede → enrich descriptions
python3 scripts/build_experts.py         # OpenAlex API → expert profiles
python3 scripts/copy_antweb_photos.py    # AntWeb images → public/images/
python3 scripts/copy_thesis_photos.py    # Thesis specimen images → public/images/
python3 scripts/improve_characters.py    # Translate character names IT + body regions
python3 scripts/enrich_publications.py   # OpenAlex → structured publications

# Deploy
npx vercel deploy --prod --force   # from formiche-ditalia/
```

## Key Architecture Decisions

### Identification Key Scoring (unique feature)
- **Weighted scoring**: Character selections weighted by Shannon entropy at selection time
- **Subfamily-aware**: When all selected characters share one subfamily_scope, out-of-scope genera get heavy penalty (0.8x vs 0.3x for in-scope missing data)
- **4-component UX**: Progress bar, gap indicator, impact badges (-N), suggested character
- Located in `src/components/IdentificationKey.tsx` (~600 lines)

### i18n Model
- Single-URL with Italian canonical paths
- 133 translation keys in `src/i18n/{it,en}.json`
- UI strings: `data-i18n="key"` swapped by LanguageSwitcher
- Data fields: `data-i18n-field="name" data-it="..." data-en="..."` for bilingual content
- LanguageSwitcher + React components listen to `langchange` custom event

### React Islands (client-side only)
- `IdentificationKey.tsx` — Multi-access key engine with scoring
- `LanguageSwitcher.tsx` — IT/EN toggle
- `GeneraBrowser.tsx` — Search + subfamily filter for genera index
- `ExpertsBrowser.tsx` — Search + region filter for experts index
- `ImageLightbox.tsx` — Click-to-zoom specimen photos
- `HeroCarousel.tsx` — Rotating genus showcase on homepage
- `GlossaryTooltip.tsx` — Hover tooltip for morphological terms
- `FilterBar.tsx` — Generic filter component (unused, replaced by specific browsers)

### Data Pipeline
NEXUS files → `parse_nexus.py` → JSON → `parse_excel.py` enrichment → `improve_characters.py` IT translation → website build. Species photos from two sources: AntWeb ML Platform images + thesis specimen directory.

## Data Sources

### NEXUS Matrices (primary)
Prefer `TESI FORMICHE (Dropbox)/Matrici corrette da Rigato/` (Rigato-validated), fallback to `TESI FORMICHE/`. Parser handles quoted multi-word names, polymorphic states `{0 1}`, and taxonomic typos.

### Specimen Images (two sources)
1. `AntWeb_ML_Platform/antweb_images/` — Organized as `{Genus}/{species}/`
2. `Formiche/Specie/{Subfamily}/{Species name}/` — AntWeb convention `{id}_{view}_{n}_high.jpg`

### Thesis Reference
"Chiave interattiva per il riconoscimento dei generi di Formicidae italiani e delle specie della città di Roma" — F.S. Mensa, Roma Tre, 2016-2017. Available on ResearchGate.
